AETHERA — 3D Library (first interactive build)

Extract the ZIP. Open PowerShell in the extracted AETHERA-3D-LIBRARY folder and run:
powershell -ExecutionPolicy Bypass -File .\START-AETHERA.ps1

Open http://127.0.0.1:8777/index.html

Controls: drag mouse to look around; W/A/S/D to walk; click glowing floating books to open; Next and Previous turn scrapbook pages.
Puzzle: moon, heart, star. No skip button. Key completion saved in this browser.

Requires internet for Three.js CDN and optional Google Fonts. This build has no account or cloud sync. Story pages are curated demo content; photos and recording uploads are not implemented in this first 3D build.

This is a standalone new folder. It does not overwrite any previous AETHERA files.
